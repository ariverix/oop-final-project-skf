# Личные финансы

Консольное Java-приложение для учёта доходов, расходов и бюджетов с отдельным кошельком каждого пользователя.

## Запуск

JDK 17+, Maven.

```bash
mvn clean verify
mvn exec:java
```

В IntelliJ IDEA запускается класс `ru.ariverix.finance.Main`.

## Пример

```text
register denis password123
income Зарплата 20000
income Зарплата 40000
income Бонус 3000
budget Еда 4000
expense Еда 300
expense Еда 500
budget "Коммунальные услуги" 2500
expense "Коммунальные услуги" 3000
summary
history
exit
```

После выхода кошелёк сохраняется. Для загрузки после перезапуска: `login denis password123`.

## Команды

| Команда | Назначение |
| --- | --- |
| `register <login> <password>` | Создать пользователя и войти |
| `login <login> <password>`, `logout` | Вход и выход |
| `categories` | Список категорий |
| `category add <имя>` | Создать категорию |
| `category rename <старое> <новое>` | Переименовать категорию |
| `category remove <имя>` | Удалить неиспользуемую категорию |
| `budget <категория> <сумма>` | Установить/изменить бюджет |
| `income <категория> <сумма> [описание]` | Добавить доход |
| `expense <категория> <сумма> [описание]` | Добавить расход |
| `balance`, `history` | Баланс и операции |
| `summary [all или категории] [дата с] [дата по]` | Статистика |
| `transfer <логин> <сумма>` | Перевод другому пользователю |
| `export <файл.json>`, `import <файл.json>` | Экспорт и импорт кошелька |
| `help`, `exit` | Справка и завершение |

Категории с пробелами пишутся в кавычках: `expense "Коммунальные услуги" 500`. Для выборки нескольких категорий: `summary Еда,Такси`. Для периода: `summary all 2026-11-01 2026-11-30`.

Суммы хранятся в `BigDecimal` с двумя знаками после запятой. Предупреждения появляются при использовании 80% бюджета, превышении лимита и отрицательном или нулевом балансе. Остаток бюджета учитывает все операции кошелька.

## Архитектура

- `model` — кошелёк, операция, отчёт.
- `core` — бизнес-логика, расчёты, интерфейсы хранилищ.
- `infra` — JSON-хранилище пользователей и кошельков.
- `cli` — команды и вывод данных.

Во время работы данные находятся в памяти. При выходе кошелёк записывается в `data/wallets/`, при входе — загружается обратно. Реестр пользователей расположен в `data/users.json`, пароли хранятся только в виде хешей. Каталог `data/` исключён из Git.

`export` и `import` работают с JSON-снимком своего кошелька. При переводе создаются расход у отправителя и доход у получателя. Приложение рассчитано на один процесс; параллельное изменение файлов разными копиями не поддерживается.

## Проверка

```bash
mvn test
mvn verify
```

Тесты проверяют авторизацию, раздельные кошельки, операции, бюджеты, предупреждения, фильтрацию, работу с файлами, переводы и консоль. `mvn verify` запускает Checkstyle. GitHub Actions выполняет ту же проверку при отправке изменений.
